## 概念释义

1. **DDD** — 以统一语言与限界上下文承载复杂业务。
   https://www.domainlanguage.com/ddd/

2. **统一语言** — 业务与代码共用词表。
   https://martinfowler.com/bliki/UbiquitousLanguage.html

3. **限界上下文** — 模型与语言一致适用的边界。
   https://martinfowler.com/bliki/BoundedContext.html

4. **C4** — Context / Container / Component / Code。
   https://c4model.com/

5. **OAuth 2.0** — 委托授权；不定义登录语义。
   https://oauth.net/2/

6. **OIDC** — 基于 OAuth 的身份层。
   https://openid.net/developers/how-connect-works/

7. **JWT** — 可验签的紧凑声明。
   https://jwt.io/introduction

8. **SCIM** — 跨域用户与组供给。
   https://scim.cloud/

9. **OpenAPI** — HTTP API 机器可读契约。
   https://www.openapis.org/what-is-openapi

10. **零信任** — 持续验证，不默认信任网络位置。
   https://csrc.nist.gov/pubs/sp/800/207/final

11. **ISMS** — 信息安全管理体系（ISO/IEC 27001）。
   https://www.iso.org/standard/27001

12. **CI** — 频繁合并并自动验证。
   https://martinfowler.com/articles/continuousIntegration.html

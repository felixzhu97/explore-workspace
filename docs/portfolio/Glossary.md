# Glossary

## Business Domains | 业务域总览

| 中文 | English | 定义 | 举例 |
|------|---------|------|------|
| 认证 | Auth | 投资者或投顾登录并建立会话的过程。 | 口令登录；OAuth 授权码 |
| 客户 | Customer | 接受投顾服务或自行管理资产的投资者主体。 | 店面下单用户 alice |
| 账户 | Account | 客户名下用于持仓与资金往来的证券或资金账户。 | alice@example.com 账号 |
| 标的 | Instrument | 可报价、委托与持仓的金融工具。 | AAPL 普通股 |
| 市场数据 | MarketData | 标的价格、成交量等行情观测。 | AAPL 日线 OHLCV |
| 组合 | Portfolio | 客户账户下按策略归集的资产集合。 | 「稳健」组合净值 |
| 持仓 | Position | 组合内对某一标的的数量与成本状态。 | 100 股 AAPL 多头 |
| 自选 | Watchlist | 客户关注但未必持有的标的列表。 | 自选 AAPL, MSFT |
| 行情 | Quote | 标的在某一时点的买卖报价。 | 买一 189.2 / 卖一 189.3 |
| 交易 | Trading | 下达委托并达成买卖的过程。 | 限价买 100 股 AAPL |
| 支付 | Payment | 账户相关资金收付的过程。 | Stripe / 银行卡扣款 |
| 清算 | Settlement | 成交后证券与资金的交收过程。 | T+1 证券交收 |
| 分析 | Analytics | 对组合收益、风险与流水的度量分析。 | 对组合收益、风险与流水的度量分析 |
| 债券 | Bond | 约定还本付息的债权类标的。 | 约定还本付息的债权类标的 |
| 期权 | Option | 在约定条件买卖标的的权利合约。 | 在约定条件买卖标的的权利合约 |
| 区块链演示 | Blockchain | 以链式账本演示链上资产或交易的能力。 | 以链式账本演示链上资产或交易的能力 |
| 横切 | Common | 跨业务域共享的内核与基础设施能力。 | 跨域共享内核（异常、基类） |

## Core Entities | 核心实体

| 中文 | English | 定义 | 举例 |
|------|---------|------|------|
| 客户 | Customer | 与投顾平台建立业务关系的投资者。 | 店面下单用户 alice |
| 账户 | Account | 记录持仓、资金与交易权限的账户。 | alice@example.com 账号 |
| 标的 | Instrument | 股票、债券、期权等可交易工具。 | AAPL 普通股 |
| 组合 | Portfolio | 账户内用于管理持仓的投资组合。 | 「稳健」组合净值 |
| 持仓 | Position | 组合对某一标的的多空数量与成本。 | 100 股 AAPL 多头 |
| 自选 | Watchlist | 客户自定义的关注标的清单。 | 自选 AAPL, MSFT |
| 自选明细 | WatchlistItem | 自选列表中的一条标的记录。 | 自选列表中的一条标的记录 |
| 行情 | Quote | 标的最新或深度报价。 | 买一 189.2 / 卖一 189.3 |
| 委托 | Order | 向市场或柜台提交的买卖指令。 | 待支付订单 #1001 |
| 成交 | Trade | 委托部分或全部成交后的交易事实。 | 委托部分或全部成交后的交易事实 |
| 支付 | Payment | 一笔资金转入或转出账户的记录。 | Stripe / 银行卡扣款 |
| 清算 | Settlement | 成交对应的交收状态与结果。 | T+1 证券交收 |
| 资金流水 | CashTransaction | 账户现金增减的流水记录。 | 账户现金增减的流水记录 |
| 风险指标 | RiskMetric | 度量组合或持仓风险的指标。 | 度量组合或持仓风险的指标 |
| 市场数据 | MarketData | 持久化保存的行情或市场观测记录。 | AAPL 日线 OHLCV |
| 债券 | Bond | 具有面值、票息与到期日的债权工具。 | 具有面值、票息与到期日的债权工具 |
| 期权 | Option | 看涨或看跌等权利类型的期权合约。 | 看涨或看跌等权利类型的期权合约 |
| 会话 | Session | 认证后持续有效的登录会话。 | JSESSIONID 登录会话 |
| 用户凭证 | UserCredential | 用于登录校验的凭证材料。 | 用于登录校验的凭证材料 |
| 用户偏好 | UserPreference | 投资者对展示与通知等的偏好。 | 投资者对展示与通知等的偏好 |

## Domain Kernel | 领域内核

| 中文 | English | 定义 | 举例 |
|------|---------|------|------|
| 实体标识 | Entity ID | 聚合或实体的唯一标识。 | UUID 主键 |
| 类型化标识 | Typed Id | 带类型约束的标识值对象。 | 带类型约束的标识值对象 |
| 值对象基类 | Abstract Embeddable | 可嵌入实体的值对象基类型。 | @Embeddable Money |
| 不可变实体基类 | Abstract Immutable | 创建后不再变更的实体基类型。 | 创建后不可变基类 |
| 可变实体基类 | Abstract Entity | 允许变更并跟踪更新的实体基类型。 | 带 @Version 的可变基类 |
| 金额 | Money | 由币种与数值构成的货币量。 | 由币种与数值构成的货币量 |
| 币种 | Currency Code | ISO 4217 货币代码。 | ISO 4217 货币代码 |
| 交易代码 | Symbol | 标的在交易所或目录中的代码。 | 标的在交易所或目录中的代码 |
| 数量 | Quantity | 委托、成交或持仓的计量数量。 | 委托、成交或持仓的计量数量 |
| 资产类别 | Asset Class | 标的所属的资产分类。 | 标的所属的资产分类 |
| 账户类型 | Account Type | 资金户、证券户等账户分类。 | 资金户、证券户等账户分类 |
| 账户状态 | Account Status | 账户是否可交易或已冻结等状态。 | 账户是否可交易或已冻结等状态 |
| 委托方向 | Order Side | 买入或卖出方向。 | 买入或卖出方向 |
| 委托类型 | Order Type | 市价、限价等委托方式。 | 市价、限价等委托方式 |
| 委托状态 | Order Status | 委托从提交到完成或撤销的状态。 | 委托从提交到完成或撤销的状态 |
| KYC 状态 | Kyc Status | 客户身份核验所处阶段。 | 客户身份核验所处阶段 |

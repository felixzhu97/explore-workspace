# Glossary | Explore Chat

> 统一语言。列仅为 **名称 / Name**、**定义 / Definition**。  
> 名称：中文在前、英文在后。定义：中文在上、英文换行；定义含举例。

## Business Domains | 业务域总览

| 名称 / Name | 定义 / Definition |
| ----------- | ----------------- |
| 认证 / Auth | 核实主体身份或授予访问权限的过程（如：口令登录；OAuth 授权码）。<br>The process of verifying the identity of an entity or granting access. (e.g. 口令登录；OAuth 授权码). |
| 用户 / User | 可登录并被授权的人员主体（如：登录主体 alice）。<br>Entities that can log in and be authorized. (e.g. 登录主体 alice). |
| 聊天 / Chat | 参与者之间的会话式交流（如：私聊「你好」；群聊「项目组」）。<br>Conversational interaction among participants. (e.g. 私聊「你好」；群聊「项目组」). |
| 消息 / Message | 通信中传递的一条信息单元（如：IM「晚上开会」）。<br>A unit of information transmitted in communication. (e.g. IM「晚上开会」). |
| 通话 / Call | 实时语音或视频通话（如：WebRTC 一对一语音）。<br>Real-time voice or video calls. (e.g. WebRTC 一对一语音). |
| 群组 / Group | 由多名用户组成的社交群体（如：「产品组」群聊）。<br>A social group consisting of multiple users. (e.g. 「产品组」群聊). |
| 帖子 / Post | 用户发布到信息流的一条内容（如：图文帖「周末出游」）。<br>A piece of content posted by a user to the feed. (e.g. 图文帖「周末出游」). |
| 信息流 / Feed | 按时间或相关性排列的内容流（如：首页时间线刷帖）。<br>Content feed sorted by time or relevance. (e.g. 首页时间线刷帖). |
| 短视频 / Reels | 短视频形态的内容流（如：15 秒竖屏短视频）。<br>A content stream in the form of short videos. (e.g. 15 秒竖屏短视频). |
| 探索 / Explore | 发现与浏览内容的入口（如：探索页九宫格）。<br>Entry point for discovering and browsing content. (e.g. 探索页九宫格). |
| 评论 / Comment | 对内容发表的附言（如：帖下回复「赞！」）。<br>Postscripts to published content. (e.g. 帖下回复「赞！」). |
| 关注 / Follow | 订阅另一用户更新的关系（如：alice 关注 bob）。<br>Relationship for subscribing to another user's updates. (e.g. alice 关注 bob). |
| 搜索 / Search | 按条件查找信息的过程（如：搜索「旅行」帖子）。<br>The process of finding information based on criteria. (e.g. 搜索「旅行」帖子). |
| 通知 / Notification | 向用户告知事件的提示（如：「bob 赞了你的帖」）。<br>A notice that informs the user of an event. (e.g. 「bob 赞了你的帖」). |
| 媒体上传 / Media | 图像、音视频等多媒体内容（如：上传 JPG / MP4）。<br>Multimedia content such as images, audio, and video. (e.g. 上传 JPG / MP4). |
| 状态 / Status | 用户短暂展示的状态更新。<br>Status updates briefly displayed to users. (e.g. 用户短暂展示的状态更新). |
| 图片生成 / Image Gen | 由提示生成图像。<br>Generate images from prompts. (e.g. 由提示生成图像). |
| 视频生成 / Video Gen | 由提示生成视频。<br>Generate videos from prompts. (e.g. 由提示生成视频). |
| 语音合成 / Voice Gen | 由文本生成语音。<br>Generate speech from text. (e.g. 由文本生成语音). |
| 视觉审核 / Vision | 对图像或视频进行理解与分析（如：NSFW 审核打标）。<br>Understand and analyze images or videos. (e.g. NSFW 审核打标). |
| 分析 / Analytics | 对使用与业务数据的度量分析。<br>Metric analysis of usage and business data. (e.g. 对使用与业务数据的度量分析). |
| 广告 / Ads | 面向用户投放的广告。<br>Ads served to users. (e.g. 面向用户投放的广告). |
| 管理 / Admin | 系统管理与运营能力（如：运营后台管理员）。<br>System management and operational capabilities. (e.g. 运营后台管理员). |
| 本地 AI / AI Chat | 与模型进行的文本对话。<br>Text conversation with the model. (e.g. 与模型进行的文本对话). |
| Explore AI 代理 / Explore AI BFF | 面向客户端聚合 AI 能力的后端中间层。<br>Backend middleware layer that aggregates AI capabilities for clients. (e.g. 面向客户端聚合 AI 能力的后端中间层). |
| 健康检查 / Health | 系统可用性与就绪状态的检查。<br>Checking system availability and readiness. (e.g. 系统可用性与就绪状态的检查). |

| 客户端身份 / Client Identity | 客户端的稳定身份标识（如：App / Web 客户端标识）。<br>Stable identity of the client. (e.g. App / Web 客户端标识). |
| 主目的地 / Primary Destination | 应用主导航的目标位置。<br>Target location of the app's main navigation. (e.g. 应用主导航的目标位置). |

| IAM 模块范围 / IAM Module Scope | 访问令牌上约束模块能力的范围声明。<br>Scope declaration that restricts module capabilities on the access token. (e.g. 访问令牌上约束模块能力的范围声明). |
| RPC 状态 / RpcStatus | 表示远程调用错误的状态对象。<br>A status object indicating a remote invocation error. (e.g. 表示远程调用错误的状态对象). |
| 分页令牌 / Page Token | 用于继续分页的不透明令牌（如：pageToken=abc 翻页）。<br>Opaque token used to continue pagination. (e.g. pageToken=abc 翻页). |
| 自定义方法 / Custom Method | 在标准 CRUD 之外以动词命名的资源操作。<br>Resource operations named with verbs beyond standard CRUD. (e.g. 在标准 CRUD 之外以动词命名的资源操作). |
| 搜索范围 / Search Scope | 搜索所覆盖的对象类型范围。<br>The range of object types covered by the search. (e.g. 搜索所覆盖的对象类型范围). |
| 语音合成目标语言 / Voice Gen Target Language | 语音合成的目标语言。<br>The target language for speech synthesis. (e.g. 语音合成的目标语言). |
| 语音翻译目标语言 / Voice Translate Target Language | 语音翻译的目标语言。<br>Target language for voice translation. (e.g. 语音翻译的目标语言). |
| 客户端消息 ID / Client Message ID | 由发送方生成的消息幂等标识（如：msg_01H…）。<br>Idempotent identifier of the message generated by the sender. (e.g. msg_01H…). |
| 消息投递状态 / Message Delivery Status | 消息从发送到已读的投递状态（如：sent → delivered → read）。<br>Delivery status of messages from sent to read. (e.g. sent → delivered → read). |
| 会话 ID / Chat Id | 会话的唯一标识（如：sess_01HXYZ…）。<br>Unique identifier for the session. (e.g. sess_01HXYZ…). |

| IM 契约 / IM Contract | 即时通讯跨端消息与会话的协议契约。<br>Protocol contract for instant messaging cross-platform messages and conversations. (e.g. 即时通讯跨端消息与会话的协议契约). |
| 不可变基类 / Abstract Immutable | 创建后不可变实体的基类型（如：创建后不可变基类）。<br>Base type of an immutable entity after creation. (e.g. 创建后不可变基类). |
| 实体基类 / Abstract Entity | 可变实体的持久化基类型（如：带 @Version 的可变基类）。<br>The persistence base type of the mutable entity. (e.g. 带 @Version 的可变基类). |
| 聚合根基类 / Abstract Aggregate Root | 聚合根实体的基类型。<br>The base type of the aggregate root entity. (e.g. 聚合根实体的基类型). |

## Domain Model | 领域模型补遗

| 名称 / Name | 定义 / Definition |
| ----------- | ----------------- |
| 会话参与者 / Chat Participant | 属于某一会话并具有角色的用户成员（如：alice 在会话中）。<br>User members who belong to a session and have roles. (e.g. alice 在会话中). |
| 群组成员 / Group Participant | 属于某一社交群组的用户成员（如：alice ∈「工程」组）。<br>A user member belonging to a particular social group. (e.g. alice ∈「工程」组). |
| 会话标题 / Chat Title | 会话的显示名称（如：「关于年假政策」）。<br>Display name of the session. (e.g. 「关于年假政策」). |
| 会话类型 / Chat Type | 私聊、群聊等会话分类（如：DM / GROUP）。<br>Conversation categories such as private chats, group chats, etc. (e.g. DM / GROUP). |
| 通话状态 / Call Status | 通话从发起、接通到结束所处的状态。<br>The status of a call from initiation, connection to termination. (e.g. 通话从发起、接通到结束所处的状态). |
| 消息正文 / Message Body | 消息所承载的文本或结构化内容（如：正文「晚上开会」）。<br>The textual or structured content carried by a message. (e.g. 正文「晚上开会」). |
| 消息类型 / Message Type | 文本、媒体等消息形态分类（如：text / image / system）。<br>Classification of message types such as text, media, etc. (e.g. text / image / system). |
| 消息反应 / Message Reaction | 用户对消息作出的表情或态度回应（如：对消息点 👍）。<br>The user's emoji or reaction to the message. (e.g. 对消息点 👍). |
| 媒体类型 / Media Type | 图像、视频、音频等内容类型。<br>Content types such as images, videos, and audio. (e.g. 图像、视频、音频等内容类型). |
| 发送方标识 / Sender Id | 发出消息的用户标识。<br>The user ID of the user who sent the message. (e.g. 发出消息的用户标识). |
| 头像地址 / Avatar URL | 用户头像资源的网络地址。<br>The web address of the user's profile picture resource. (e.g. 用户头像资源的网络地址). |
| 认证令牌对 / Auth Tokens | 登录后用于访问与续期的令牌组合。<br>The token combination used to access and renew after login. (e.g. 登录后用于访问与续期的令牌组合). |
| 用户关注 / User Follow | 用户之间单向关注关系（如：alice 关注 bob）。<br>One-way follow relationship between users. (e.g. alice 关注 bob). |
| 客户端消息号 / ClientMsgId | 发送端生成的消息幂等编号（如：客户端去重 id）。<br>Idempotent number of the message generated by the sender. (e.g. 客户端去重 id). |
| 消息已读 / Message Read | 接收方已阅读某消息的事实（如：已读回执）。<br>The fact that the recipient has read a message. (e.g. 已读回执). |
| 消息已接受 / Message Accepted | 会话时间线已接纳某消息的事实（如：入站消息验收通过）。<br>The fact that the conversation timeline has accepted a message. (e.g. 入站消息验收通过). |
| 投递状态变更 / Delivery Status Changed | 消息投递状态发生变化的事实。<br>The fact that the message delivery status has changed. (e.g. 消息投递状态发生变化的事实). |
| 线程已灌库 / Thread Hydrated | 本地会话时间线已用权威数据填满的事实（如：线程消息已灌入内存）。<br>The fact that the local session timeline has been filled with authoritative data. (e.g. 线程消息已灌入内存). |
| 目录已替换 / Catalog Replaced | 会话目录被完整替换的事实（如：目录快照整体替换）。<br>The fact that the session directory was completely replaced. (e.g. 目录快照整体替换). |
| 预览已变更 / Chat Preview Changed | 会话列表预览信息已更新的事实（如：会话预览文案更新）。<br>The fact that the preview information in the conversation list has been updated. (e.g. 会话预览文案更新). |
| 末条消息已变更 / Last Message Changed | 会话最后一条消息预览已更新的事实（如：末条消息指针更新）。<br>The fact that the preview of the last message in the conversation has been updated. (e.g. 末条消息指针更新). |

# E3 操作台

← [用户故事地图](../User-Story-Map.md)

## 背景

`web/` 为每个 ML 模块提供一页与图表，便于兄弟产品接入 BFF 前先验证路由。

---

## US-09 模块页

**As a** 测模工程师  
**I want** 推荐、视觉、RAG、图像、语音、视频各有 UI 页  
**So that** 可在操作台逐模块演练

### 验收标准

1. **Scenario** 每模块提交测试请求  
   **GIVEN** `web/` 运行于 :4210  
   **WHEN** 打开各模块路由  
   **THEN** 可提交测试请求并展示结构化结果

### 状态

已实现

---

## US-10 每模块页 D3 图表

**As a** 测模工程师  
**I want** 每模块页带 D3 图表  
**So that** 分数与序列可读，不必只盯原始 JSON

### 验收标准

1. **Scenario** 数值序列成图  
   **GIVEN** 模块成功返回含数值序列的响应  
   **WHEN** 页面渲染  
   **THEN** D3 图表可视化该结果

### 状态

已实现

---

## US-11 RAG 嵌入图谱

**As a** 测模工程师  
**I want** RAG 页提供 PCA 嵌入图谱  
**So that** 导出向量的簇形可见

### 验收标准

1. **Scenario** RAG 上 PCA 散点  
   **GIVEN** RAG 向量可用  
   **WHEN** 打开 RAG 页图谱  
   **THEN** 展示 PCA 散点图

### 状态

已实现

---

## US-12 评估看板

**As a** 测模工程师  
**I want** `web/` 内有评估看板  
**So that** 可跨模块比较测试跑质量指标

### 验收标准

1. **Scenario** 评估指标汇总  
   **GIVEN** 操作台  
   **WHEN** 评估能力上线  
   **THEN** 看板页汇总测试评估指标

### 状态

规划中
